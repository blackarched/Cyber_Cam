# NEXUS Security Grid Deployment Guide

This guide provides instructions on how to deploy the NEXUS Security Grid to a production environment.

## Prerequisites

*   A server with Docker and Docker Compose installed.
*   A production-ready PostgreSQL database.
*   A production-ready Redis instance.
*   A HashiCorp Vault instance for secrets management.

## 1. Clone the Repository

Clone the repository to your server:

```
git clone https://github.com/your-username/your-repo.git
cd your-repo
```

## 2. Configure the Environment

Create a `.env` file from the `.env.example` file:

```
cp .env.example .env
```

Edit the `.env` file and provide the following information:

*   `JWT_SECRET`: A long, random string for signing JWTs.
*   `DB_HOST`: The hostname of your PostgreSQL database.
*   `DB_PORT`: The port of your PostgreSQL database.
*   `DB_USER`: The username for your PostgreSQL database.
*   `DB_PASSWORD`: The password for your PostgreSQL database.
*   `DB_NAME`: The name of your PostgreSQL database.
*   `REDIS_HOST`: The hostname of your Redis instance.
*   `REDIS_PORT`: The port of your Redis instance.
*   `VAULT_ENDPOINT`: The endpoint of your HashiCorp Vault instance.
*   `VAULT_TOKEN`: The token for your HashiCorp Vault instance.
*   `BLOCKED_IPS`: A comma-separated list of IP addresses to block.
*   `FRONTEND_ORIGIN`: The origin of your frontend application.

## 3. Configure HashiCorp Vault

Store the following secrets in your HashiCorp Vault instance at the path `secret/data/nexus`:

*   `JWT_SECRET`
*   `DB_HOST`
*   `DB_PORT`
*   `DB_USER`
*   `DB_PASSWORD`
*   `DB_NAME`
*   `REDIS_HOST`
*   `REDIS_PORT`

## 4. Build and Launch the Application

Build and launch the Docker containers:

```
docker-compose up -d --build
```

## 5. Access the Application

You can now access the application at the following URLs:

*   **Dashboard:** `https://your-domain.com`
*   **API Docs (Swagger):** `https://your-domain.com/api-docs`
*   **API Health:** `https://your-domain.com/api/health`
*   **API Readiness:** `https://your-domain.com/api/ready`
*   **Prometheus Metrics:** `http://your-domain.com:9090`
